# 02. 解析シート v2：記入ガイド

参考曲 1 曲を、**「シートを読めば、その曲を思い出して歌える」**レベルまで分解して記録します。
音源ファイルそのものは保存しません。保存するのは「作り方（レシピ）」です。

型定義は `templates/analysis_sheet.schema.json`、記入例は `templates/analysis_sheet.example.json` にあります。

## 分析の進め方（1 曲あたり 10〜15 分の人の作業）

```
① 音源を用意する（正規に購入・契約したもの）
② 自動分析：BPM・キー・セクション分割・音量曲線・楽器分離・MIDI 化・コード推定・グルーヴ計測
③ 歌詞テキストを Claude が分析：テーマ・韻・音節数・起伏
④ 世界観・バックボーン・ライブの場を Claude が公開情報から調査
④' MV・公式サイト・SNS・ライブ映像の URL を集め、Claude が視覚言語と運用を分析（I. の欄）
⑤ 人が聴きながら「クセ」「奏法」「エフェクト」「環境音」「印象付ける要素」を口述
⑥ Claude が ①〜⑤ を統合して解析シートを完成させ、データベースに保存
```

機械分析が下書きを作り、人は⑤だけ埋めます。

## 自動分析に使う道具

| 分析 | 道具 | 精度 |
|---|---|---|
| BPM・キー・セクション分割・音量曲線 | librosa / Essentia（音楽分析ライブラリ） | 高 |
| 楽器ごとの分離 → 楽器リスト | Demucs（音源分離） ＋ 楽器分類モデル | 中〜高 |
| アルペジオ・リフ・メロディの輪郭 | Basic Pitch（音 → MIDI 変換）→ 骨格を抜き出す | 中（人の確認が必要） |
| コード進行・転調 | コード推定ツール（Chordino など） | 中 |
| グルーヴ・微妙なタイミング | 打点検出 → スイング率・ずれを計測 | 高 |
| 歌詞の構造 | Claude（歌詞テキストから） | 高 |
| 世界観・バックボーン | Claude（公開情報を調査） | 中〜高 |
| MV・ジャケット・公式サイト・SNS の視覚言語と運用 | Claude（URL を渡して分析。動画は代表的な場面の静止画を数枚） | 中〜高 |
| 奏法・エフェクト・環境音・印象 | **人の耳 ＋ Claude への口述** | 人が必須 |

## 記録する項目

### A. 歌詞（`lyrics`）

| 小項目 | 記録内容 | 生成に渡すもの |
|---|---|---|
| テーマ | 主題一文 ＋ 副題 | そのまま |
| 印象的なワード | 記憶に残る語を **カテゴリ付きで**（固有名詞 / 色 / 体の部位 / 乗り物 / 天候 …）。語そのものも記録する | **カテゴリだけ**（語そのものは渡さない） |
| 物語の起伏 | セクションごとの「場所・時間・感情」の推移。視点の変化（私 → あなた → 私たち） | そのまま |
| 韻の踏み方 | 型（AABB / ABAB …）、母音韻か子音韻か、行末か行中か、サビで韻が密になるか | そのまま |
| 音節の数 | セクションごとの 1 行あたり音節数（例：A メロ 7-7-8-7、サビ 5-5-9-5）。メロディの密度そのもの | そのまま |
| タイトル語 | 出現回数・位置（サビ頭 / サビ尻 / ブリッジ）、タイトルを **言わずに連想させる行** の手法 | 手法だけ |
| 感情のトーン | セクション別（例：A メロ「諦め」→ サビ「開放」）。皮肉・ユーモアの有無 | そのまま |
| 言語 | 主言語、混在言語とその使われ方（掛け声だけ / 1 行だけ） | そのまま |
| その他 | 語り / ラップ部分、繰り返しの型（同じ行を少し変えて反復 など） | そのまま |

### B. 世界観（`worldview`）

| 小項目 | 記録内容 |
|---|---|
| 舞台 | 場所・季節・時間帯・天気・移動手段 |
| 内面 | 主人公の年齢感、立場、抱えているもの、曲の中で変わるか |
| 時代感（MIX 感を含む） | 「80s シンセ × 現代の低音の太さ」のような **年代の掛け合わせ**。音像の広がり、ボーカルの前後感、低音の量、圧縮の強さ、録音の空気感（部屋鳴り / 完全に乾いた） |
| アーティストのバックボーン | 出身地・文化圏、影響源、キャリア段階、本人のテーマ性 |
| ライブの場 | 主戦場（クラブ / フェス / アリーナ / 路上）、客層、その場に合わせた曲の作られ方（例：クラブ想定なので低音が長い） |
| その他 | MV・ジャケットの視覚言語、ファッション、ブランドの一貫性 |

### C. 使用楽器（`instruments`）

| 小項目 | 記録内容 |
|---|---|
| 楽器リストと編成 | 楽器名 ＋ 役割（主役 / 伴奏 / リズム / 彩り）＋ 鳴っているセクション。編成の人数感（3 ピース / 打ち込み ＋ 生ギター …） |
| 環境音・ノイズ | 種類（雨、車のドア、街の雑踏、テープのヒス、レコードノイズ、息の音）、入る瞬間（秒数）、役割（場面転換 / 質感） |
| コンテンポラリーな構成 | 現代的な要素（808 の低音、声の切り貼り、トラップ系ハイハット、ピッチを変えた声、サイドチェーン）と、古典的な編成との共存のしかた |
| エフェクター | 楽器別（ギター：オーバードライブ / コーラス / トレモロ。ボーカル：ピッチ補正の強さ / ダブリング / ディレイの拍。シンセ：フィルターの開閉 …） |
| 全体バランス | チューニング（440 Hz / 432 Hz / 半音下げ）、各帯域の重心、音量の推移、ステレオの広さ、どの楽器が一番前にいるか |

### D. 演奏のクセ（`performance`）

| 小項目 | 記録内容 |
|---|---|
| 音符の配置 | 拍の頭に乗るか、裏に置くか、前に突っ込むか後ろにもたれるか。休符の使い方（歌の前に必ず 1 拍空ける など） |
| メロディのクセ | 跳躍が多いか順次進行か、同音連打、語尾の下げ方 / しゃくり、フレーズ末の伸ばし方、使う音階（ペンタトニック / ブルーノート / モード） |
| 奏法（多角的に） | ギター：指 / ピック / スライド / ボトルネック / ドリル / 弓 / タッピング。ベース：指 / ピック / スラップ / フレットレス。ドラム：生 / 打ち込み / ブラシ / ロッズ / 人力の揺れ。鍵盤：ペダルの踏み方、アルペジオの型と速さ。ボーカル：地声 / 裏声の切り替え点 |
| フィルと装飾 | ドラムのフィルの頻度と位置、ギターのオブリガート（歌の合間の合いの手）の癖 |

### E. 和声と転調（`harmony`）

| 小項目 | 記録内容 |
|---|---|
| 転調の数 | 回数と位置（例：ラスサビで半音上げ、ブリッジで短調へ） |
| 転調の傾向 | 型（半音上げ / 平行調 / 同主調 / 突然の遠隔転調）、戻り方 |
| コード感 | 進行の性格（ループ型 / 循環型 / 展開型）、借用和音・テンションの多さ、ベースの動き（ペダル / 歩く） |

### F. グルーヴとテンポ（`groove`）

| 小項目 | 記録内容 |
|---|---|
| BPM | 実測値、倍 / 半分に感じるか、曲中の揺れ（人力なら ±2〜3） |
| グルーヴ | 真っすぐ / シャッフル / ハーフタイム、スイング率、ハイハットの刻み、キックとベースの関係（同期 / ずらし） |
| 微妙なタイミング | スネアが少し遅い、ボーカルが前乗り など（分析ツールで計測可） |

### G. 構成とフレーズ（`structure` / `phrases`）

| 小項目 | 記録内容 |
|---|---|
| 全体構成 | セクション表（名前・開始秒・小節数・エネルギー 1〜10） |
| イントロ / アウトロ | 型・長さ・最初に鳴る楽器・次への渡し方 |
| サビ | 入る秒数、盛り上げの仕掛け（ドラムが開く / 声を重ねる / 音域が上がる）、反復回数 |
| **フレーズの骨格** | 決めフレーズ（リフ・サビ頭・合いの手）を **リズム骨格 ＋ 輪郭** で記録。これが「歌える」精度を作る欄 |
| 印象付ける要素 | 「一言で思い出す要素」（特定の効果音、口笛、テープのよれ、サイドチェーンの脈動 …） |

#### フレーズの骨格の書き方

```
リズム骨格 :  ♩ ♪♪ | ♩ ー        （1 小節ごとに | で区切る。♩=4 分、♪=8 分、ー=伸ばし、・=休み）
輪郭       :  上 → 上 → 下 → 伸ばす   （前の音より上がったか下がったか）
開始音     :  主音の 5 度上           （調の中での相対位置。絶対音名は書かない）
長さ       :  2 小節
楽器       :  シンセリード ＋ ボーカル重ね
出現       :  イントロ・各サビ頭・アウトロ（計 5 回）
```

### H. ボーカル（`vocal`）

| 小項目 | 記録内容 |
|---|---|
| 音域 | 低 / 中 / 高、地声の上限、裏声の使用域 |
| 声質 | 形容詞で（息混じり / ざらつき / 澄んだ / 鼻にかかる / 太い / 細い …）。**「○○に似た声」とは書かない** |
| 歌い方 | なめらか / 刻む / 語り、ビブラートの深さと速さ、しゃくり、語尾の処理 |
| 表現 | 息の混ぜ方、アドリブの頻度と型、重ね方（ユニゾン / 3 度 / オクターブ）、掛け合い |
| 加工 | ピッチ補正の強さ、ダブリング、ディレイ・リバーブの量、ローファイ処理 |

### I. ビジュアルと Web 上の表現（`visual_web`）

音源だけでなく、**MV・アーティスト公式サイト・SNS・ライブ映像・インタビュー動画**も分析対象にします。
この欄は、将来の**ジャケット自動生成**と SNS 動画の参考資料にもなります。

| 小項目 | 記録内容 | 分析元 |
|---|---|---|
| 分析した URL | MV / 公式サイト / SNS 各アカウント / ライブ映像 / インタビュー。取得日も記録 | ― |
| MV の視覚言語 | 舞台（屋内 / 屋外 / 車内 / 抽象）、色調（暖 / 寒 / 無彩色）、光の質（自然光 / ネオン / 逆光）、カメラの動き（固定 / 手持ち / ドローン）、カット割りの速さ、物語性の有無、象徴的なモチーフ | MV |
| ジャケットの構成 | 構図（中央 / 余白多め / 全面写真）、被写体（本人 / 風景 / 抽象 / タイポグラフィのみ）、色数、文字の有無と書体の雰囲気、質感（写真 / イラスト / 3D / コラージュ）、シリーズとしての統一ルール | 各配信サービスのジャケット |
| 公式サイト | 情報の密度、トーン（ミニマル / 情報過多）、使っている色と書体、ファンに向けた導線（グッズ / ライブ / メルマガ） | HP |
| SNS の運用 | 主戦場の媒体、投稿頻度、内容の比率（制作過程 / 日常 / 告知 / ファン交流）、文体（短文 / 長文 / 絵文字）、動画の尺と形式、コメントへの返し方 | Instagram / TikTok / X / YouTube |
| ライブ映像 | 演出（照明の色・動き）、ステージの大きさ、客の反応、曲の生アレンジの違い | ライブ映像 |
| ブランドの一貫性 | 音・映像・ジャケット・SNS が同じ世界観で統一されているか。ズレがあればどこか | 横断 |
| 画像生成に渡すための要約 | 上記を 3〜5 行に圧縮した「ビジュアルの指示文の種」（色調・光・構図・質感・モチーフ） | ― |

**この欄で記録しないもの**：MV の映像そのもの、ジャケット画像そのもの、SNS の投稿文そのもの（URL と要約だけ残す）。
ジャケット生成に渡すのは「構図・色調・光・質感・モチーフのカテゴリ」までで、画像を模写させることはしません。

## やってはいけないこと

- 実在のアーティスト名を Suno の指示文に入れない（Suno 側でも弾かれます）
- 歌詞の文章・メロディの音程をそのまま生成に渡さない。渡すのは「カテゴリ」「構造」「骨格」まで
- 解析シートを外部に公開しない（クローズドな保管庫の中だけで使う）

## 法的な補足

日本の著作権法 30 条の 4 は、作品を「享受」する目的ではない**情報解析**のための利用を認めています。
分析自体はこの範囲ですが、**出力（作った曲）が元の曲に似すぎれば別問題**です。
似すぎを防ぐのが `docs/04_borrowing_rules.md` のルールです。
