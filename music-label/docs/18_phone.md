# 18. 外出先からスマホで進める（2026-10-22〜・決定 28）

Mac は家で動かしたまま。スマホから Mac のダッシュボードにつないで、作曲から DistroKid の登録まで進める。

- **つなぐ道**：Tailscale（Mac とスマホだけをつなぐ専用の通り道。インターネットには公開しない。個人は無料）
- **スマホのページ**：`https://<この Mac の名前>.ts.net/phone`（家の Wi-Fi なら `http://<Mac の IP>:8765/phone?key=…` でも）

## 1. 最初に 1 回だけ（Mac とスマホ）

| # | どこで | やること |
|---|---|---|
| 1 | Mac | App Store で「Tailscale」を入れてログイン（Google アカウントで可） |
| 2 | iPhone | App Store で「Tailscale」を入れて、**同じアカウント**でログイン → つなぐ（VPN をオン） |
| 3 | Mac のターミナル | `tailscale serve --bg 8765`（ダッシュボードを、自分の機器だけから https で開けるようにする。「HTTPS を有効に」と出たら、表示のリンクを開いて有効にする）。`tailscale` が見つからないときは `/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg 8765` |
| 4 | Mac の `music-label/.env` | `WEBAPP_AWAKE=1` を足す（ダッシュボードが動いている間、Mac が勝手に眠らない） |
| 5 | Mac のターミナル | `python3 scripts/schedule.py install`（ダッシュボードを動かし直す。起動のときに「外出先のスマホ（Tailscale）：https://…/phone」と出る） |
| 6 | Mac のシステム設定 | 「バッテリー」→「オプション」→「電源アダプタに接続中は、ディスプレイがオフのときに自動でスリープさせない」をオン。MacBook はふたを閉じると眠るので、**ふたは開けたまま**電源につないでおく |
| 7 | iPhone の Safari | 5 で出た URL を開き、共有ボタン →「ホーム画面に追加」 |

SSD はつないだままにしておく（外れているときは、Mac の「ダウンロード/SUNO楽曲」に入り、あとで SSD に写る）。

## 2. 1 曲の流れ（スマホだけで）

ホーム画面の「スマホで進める」→ 曲を選ぶ。上から順に出てくる。

1. **Suno で作る**：「Suno の作曲画面を開く」→「高度な」→ ページの 1〜11 の順に「写す」→ Suno の欄に貼る／数字とオン・オフを選ぶ → **Create は Gon さんが押す**
   - スマホの Suno に「その他のオプション」の欄が無いときは、Safari の「ぁあ」→「デスクトップ用 Web サイトを表示」で開き直す
2. **いいね → ダウンロード**（Safari のダウンロードは「ファイル」アプリの「ダウンロード」に入る）
3. **曲を送る**：「ファイルを選択」→「ブラウズ」→ ダウンロードした 1 本 →「Mac に送る」。Mac の「楽曲情報」に曲名で入り、取り込み・音量・ジャケット・下書きが自動で進む。終わると公開の準備のページに移る
4. **DistroKid に出す**：ページに戻ると下書きが出る。「音源をスマホに保存」「ジャケットをスマホに保存」→「DistroKid の登録画面を開く」→ 各欄を「写す」で貼り、ファイルは「ファイル」から選ぶ → 選ぶもの（docs/17 の 3）→ **最後の登録ボタンは Gon さんが押す**
5. **登録の記録**：配信日を選んで「DistroKid に登録した」

## 3. もう 1 つの道：Mac の画面をスマホで操作する

自動入力（Mac の専用の Chrome が欄を埋めて、読み返して確かめる）をそのまま使いたいとき。

- Mac：システム設定 →「一般」→「共有」→「画面共有」をオン
- iPhone：画面共有のアプリ（VNC のアプリ。例：RealVNC Viewer・Screens）で、Tailscale の Mac の住所（100.x.x.x）につなぐ
- スマホのページの下の「Mac の Chrome で Suno に入力する」などを押し、画面共有で中身を確かめて Create・最後の登録ボタンを押す

## 4. 安全のため

- ダッシュボードには、Tailscale につないだ自分の機器か、家の Wi-Fi で合鍵つきの URL を開いた機器からしか入れない。ルーターの「ポート開放」はしない
- ボタンも曲の受け取りも、ページに埋め込んだ毎回変わる合言葉が無いと動かない。受け取るのは曲のファイル（WAV・MP3・M4A・FLAC・AIFF。400 MB まで）だけ
- Create・ロボット確認・DistroKid の Extras・宣誓のチェック・最後の登録ボタンは、今までどおり Gon さんが押す
