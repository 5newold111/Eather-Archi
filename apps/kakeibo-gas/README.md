# 家計簿（Claudeチャット連携）

Claudeとのチャットで話した支出・収入を、Googleスプレッドシートの家計簿に登録するウェブアプリです。
Google Apps Script（GAS：Googleが無料で提供するプログラムの実行環境）で動きます。

```
Claudeに話す ─→ Claudeが「登録用テキスト」を返す ─→ アプリに貼り付け ─→ 確認して登録 ─→ スプレッドシート
「カフェで580円」      （決まった形のデータ）          （説明文ごとでOK）    （表で修正もできる）  「家計簿」シート
```

## できること

| No. | 画面 | 内容 |
|---|---|---|
| 01 | ダッシュボード | 月ごとの**支出の総額**・収入・差額と前月比、**敵1〜敵4の内訳**（割合の帯・4つのカード）、分類ごとのカテゴリ別の横棒、明細（削除可）、CSV書き出し |
| 02 | チャットから取り込む | Claudeの返答を貼ると中のデータだけを読み取り、表で確認・修正してから登録。「1,200円」「10/3」「カード」「家賃」「固定資産税」などの書き方の違いは自動でそろえる |
| 03 | 手で入力 | 日付・支出/収入・金額・カテゴリ・支払方法・メモ・事業按分を1件ずつ登録 |
| 04 | 固定費 | 家賃・保険・通信費など毎月決まった支出をリストにしておき、ボタン一つでその月の家計簿にまとめて登録。同じ月には二重に登録されない |

- **支出の4分類（敵1〜敵4）**: 支出はカテゴリごとに、次の4つのどれかに入れて集計します（変え方は下記）

  | 分類 | 名前 | カテゴリ |
  |---|---|---|
  | 敵1 | 毎月の固定費 | 住居（家賃・ローン）・水道光熱・社会保険・通信・サブスク・保険 |
  | 敵2 | 変動費 | 食費・日用品・被服・交通・医療・趣味娯楽・交際・教育・その他 |
  | 敵3 | 不定期の固定費 | 税金・年会費 |
  | 敵4 | 変動費2 | 家電家具・旅行・冠婚葬祭・治療・引越し |

  ダッシュボードの帯とカードは、敵1から順に **黒・濃いグレー・グレー・斜線** で塗り分けています（色を使わないデザインのため）
- **事業按分**: 自宅兼事務所の光熱費・通信費などを「何％を事業の経費に回すか」の目安として記録できます。ダッシュボードに、経費に回せそうな金額の合計が出ます（確定申告での実際の按分は、使用面積や使用時間などの根拠に基づいて決めてください）
- 1件でも誤りがあれば**何も登録しません**（中途半端に登録されるのを防ぐため）。誤りのある行は表で示します
- 既存の経費管理アプリには一切手を入れません。別のアプリとして並べて使えます

## 導入手順（10分ほど）

### 1. プロジェクトを作る
1. パソコンで https://script.google.com/home を開き、左上の「**新しいプロジェクト**」
2. 左上の「無題のプロジェクト」をクリックして、名前を「**家計簿**」に変更

### 2. コードを貼る
長いファイルは貼り付けの途中で切れることがあるため、**すべて100行未満のファイルに分けてあります**。
次の19ファイルを、同じ名前で作って貼り付けます。

| 種類 | GASでのファイル名（このフォルダのファイル） |
|---|---|
| スクリプト（5つ） | `コード`・`明細`・`検証`・`シート`・`集計` |
| HTML（14個） | `index`・`画面_スタイル1`〜`2`・`画面_本文1`〜`3`・`画面_ダッシュボード`・`画面_処理1`〜`7` |

1. 左側の「**コード.gs**」を開き、中身をすべて消してから、このフォルダの [`コード.gs`](コード.gs) の中身を貼り付け
2. 左側「ファイル」の横の「**＋**」→「**スクリプト**」→ 名前に `明細` と入力（`.gs` は自動で付きます）→ 中身を消して [`明細.gs`](明細.gs) を貼る。`検証`・`シート`・`集計` も同じように作る
3. 「**＋**」→「**HTML**」→ 名前に `index` と入力（**`.html` は付けない**。自動で付きます）→ 中身を消して [`index.html`](index.html) を貼る。
   `画面_` で始まる13個も同じように作る（名前は表のとおり正確に。1文字でも違うと画面が開きません）
4. **貼ったら毎回、編集欄の一番下までスクロールし、最後の行がこのフォルダのファイルと同じか確認**する
   （HTMLの最後は `</style>`・`</script>`・`</html>` などのタグ、スクリプトの最後は `}`）
5. 上部の保存ボタン（フロッピーの絵）を押す

> 画面に「『index』という HTML ファイルは見つかりませんでした」と出たら、HTMLファイルの名前が違っています
> （`index.html.html` になっている、`index` を作り忘れている など）。
> 「『画面_処理3』…見つかりませんでした」のように出たら、そのファイルを作り忘れているか名前が違っています。

### 3. 保存先を選ぶ（任意）
- **経費管理と同じスプレッドシートにまとめたい場合**: そのスプレッドシートのURL
  `https://docs.google.com/spreadsheets/d/【ここ】/edit` の【ここ】の部分をコピーし、
  `コード.gs` の冒頭 `const SPREADSHEET_ID = '';` の `''` の中に貼ります。そのスプレッドシートに「家計簿」シート（タブ）が追加されます
- **空のままの場合**: 初回の登録時に「家計簿」という新しいスプレッドシートがマイドライブに作られます

### 4. 公開する
1. 右上の「**デプロイ**」→「**新しいデプロイ**」
2. 歯車アイコン →「**ウェブアプリ**」を選ぶ
3. 「次のユーザーとして実行」: **自分**、「アクセスできるユーザー」: **自分のみ**
4. 「デプロイ」→ 初回は「アクセスを承認」を求められます
   - 自分のアカウントを選ぶ →「このアプリは Google で確認されていません」と出たら「**詳細**」→「**家計簿（安全ではないページ）に移動**」→「許可」
   - 自分で作ったアプリなので問題ありません。許可するのは「自分のスプレッドシートの読み書き」です
5. 表示された「**ウェブアプリのURL**」を開けば使えます。スマホのホーム画面に追加しておくと便利です

> **アクセスを「自分のみ」にする理由**: 家計のデータは個人情報です。「全員」にするとURLを知っている人なら誰でも見たり登録したりできてしまいます。

### コードを更新したとき（固定費の機能を追加したときも、この手順で反映します）
1. 変わったファイルの中身を、このフォルダの新しい内容に**丸ごと貼り替えて**保存。新しく増えたファイルは「＋」で作る
   （`SPREADSHEET_ID` を設定していた場合は、`コード.gs` を貼り替えた後にもう一度入れ直してください）
2. 下の「デプロイを管理」の手順で新バージョンにする

既に登録したデータはそのまま使えます。家計簿シートの右端に「固定費ID」列が自動で足され、
「固定費」シートが新しく作られるだけで、これまでの行は書き換えません。


**デプロイを管理**: 「デプロイ」→「**デプロイを管理**」→ 鉛筆アイコン →「バージョン」で「**新バージョン**」→「デプロイ」。
こうすると**URLを変えずに**中身だけ更新できます（「新しいデプロイ」を選ぶとURLが変わってしまいます）。

## Claudeへの頼み方

毎回説明しなくて済むように、claude.ai で「**家計簿**」という**プロジェクト**を作り、
プロジェクトの「**指示**（カスタム指示）」に次の文章を貼っておきます。
以降、そのプロジェクト内のチャットで「今日カフェで580円、スーパーで2,340円（PayPay）」と話すだけで、取り込める形で返ってきます。

````text
あなたは私の家計簿の記録係です。私が支出や収入について話したら、
説明は短く添えたうえで、最後に必ず次の形式の「登録用JSON」を ```json のコードブロックで出してください。

[{"date":"YYYY-MM-DD","type":"支出","amount":580,"category":"食費","method":"現金","memo":"カフェ","business_ratio":0}]

ルール:
- 1件につき1つの { } 。複数あれば配列に並べる
- date: 日付が分からなければ今日。「昨日」などは実際の日付に直す
- type: "支出" か "収入"
- amount: 円の整数（カンマや「円」は付けない）
- category:
  - 支出（敵1 毎月の固定費）: 住居 / 水道光熱 / 社会保険 / 通信 / サブスク / 保険
  - 支出（敵2 変動費）: 食費 / 日用品 / 被服 / 交通 / 医療 / 趣味娯楽 / 交際 / 教育 / その他
  - 支出（敵3 不定期の固定費）: 税金 / 年会費
  - 支出（敵4 変動費2）: 家電家具 / 旅行 / 冠婚葬祭 / 治療 / 引越し
  - 家賃・住宅ローンは住居、国民健康保険・年金は社会保険、固定資産税・住民税は税金、病院の通院は医療、手術や歯の治療など大きな治療費は治療
  - 収入: 給与 / 事業 / その他
  - 当てはまらなければ "その他" にして、memo に内容を書く
- method: 現金 / クレジット / 電子マネー / 口座振替 / その他（PayPay・Suica などは電子マネー）
- memo: お店や品目を短く（なくてもよい）
- business_ratio: 事業に使った割合（0〜100）。私が「事業用」「按分○％」と言ったときだけ入れ、それ以外は0
- 金額や日付があいまいなときは、JSONを出す前に確認の質問をする
````

**レシートの写真**を送って「家計簿に登録して」と頼むこともできます。

> 以前このテンプレートを貼った場合は、category の部分を上の新しい一覧に貼り替えてください（「衣服美容」は「被服」になりました）。
> 家賃などの毎月の固定費は、Claudeに頼まなくても「03 固定費」のボタンで登録できます。

## 固定費の使い方

1. 「03 固定費」の下のフォームで、名前・金額・引落日・カテゴリ・支払方法を入れて「リストに追加」
   - 動画配信などは「サブスク」で登録すると、ダッシュボードで敵1（毎月の固定費）として集計されます
2. 月を選んで「○年○月分の固定費を登録」を押すと、リストの全件がその月の家計簿に入ります
   - 日付は引落日。31日のようにその月に無い日は月末に寄せます（2月なら28日／29日）
   - もう一度押しても、登録済みの分は飛ばすので二重になりません。金額が月によって違う場合（電気代など）は、登録後に「01 ダッシュボード」の明細を削除して入れ直すか、リストに入れずに毎月入力してください
3. リストから外しても、これまでに登録した分は消えません

## 保存されるデータ（「家計簿」シート）

| 列 | 内容 |
|---|---|
| A | ID（削除に使う識別番号。非表示） |
| B | 日付（`2026-10-03` の形の文字） |
| C | 区分（支出 / 収入） |
| D | 金額 |
| E | カテゴリ |
| F | 支払方法 |
| G | メモ |
| H | 事業按分(%) |
| I | 登録元（手入力 / チャット） |
| J | 登録日時 |
| K | 固定費ID（固定費ボタンで登録した行だけ。二重登録の防止に使う） |

「固定費」シートには、固定費リスト（ID・名前・金額・カテゴリ・支払方法・引落日）が入ります。

シートを直接編集してもかまいません。

**カテゴリと4分類**は `コード.gs` 冒頭の `TIERS` で決めています。カテゴリを足すときは該当する分類の `categories` に名前を足し、
別の分類へ移すときは名前を移します（例: 教育を敵1に移す）。支出カテゴリの選択肢もここから作られます。
支払方法は `METHODS`、収入のカテゴリは `CATEGORIES` の `'収入'` で変えられます。
書き換えたら上の「コードを更新したとき」の手順で反映し、Claudeへの指示のカテゴリ一覧も合わせて変えてください。
過去の明細も、ダッシュボードを開いた時点のこの設定で振り分け直されます。
一覧から外したカテゴリの過去の行は敵2で集計します（以前の「衣服美容」も敵2）。

## 安全のための工夫

- メモが `=` などで始まる場合、スプレッドシートが**数式として実行しない**よう、文字として保存します（CSVも同様）
- 画面に表示する文字はすべて「ただの文字」として扱い、貼り付けた内容がプログラムとして動くことはありません
- 2つの画面から同時に登録しても、行が重なって上書きされないよう順番待ちにしています
- 外部のサイトからは何も読み込みません

```
