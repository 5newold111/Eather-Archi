# App Store 公開ガイド（丁寧版）

このガイドは、開発の知識がなくても迷わず進められるように書いています。
**あなたが手を動かすのは、大きく分けて次の3つだけです。**

| やること | 所要時間 | むずかしさ |
|---|---|---|
| STEP 1: アカウントを3つ作る | 合計30分 + Appleの承認待ち(最大2日) | クリックするだけ |
| STEP 2: AIサーバーを公開する | 10分 | クリックするだけ |
| STEP 3: コマンドを1つ実行する | 10分 + ビルド待ち30分 | 質問に答えるだけ |
| STEP 4: App Storeの入力欄を埋める | 30分 | このガイドからコピペ |

- 課金（Pro版）は**初回公開には含めません**。アプリ内の課金画面はすでにオフに
  してあるので、何もしなくて大丈夫です（審査対策済み）。課金は公開後の
  アップデートで追加します → `docs/MONETIZATION.md`
- プライバシーポリシーのページも**用意済み**です（STEP 4で貼るURLがあるだけ）。
- 途中でやめても大丈夫。どのSTEPも続きから再開できます。

---

## STEP 1: アカウントを3つ作る

### 1-A. Apple Developer Program（App Store公開に必須・有料）

- 費用: 年間 ¥14,900 前後 ／ 承認まで最大48時間かかるので**最初に**申し込む
- 一番簡単なのは iPhone から:

1. iPhoneの App Store で「**Apple Developer**」アプリを検索してインストール
2. アプリを開き、普段使っているApple IDでサインイン
3. 「**アカウント**」タブ →「**Apple Developer Programに登録**」をタップ
4. 案内に沿って本人確認（顔写真つき身分証のスキャンあり）→ 支払い
5. 「登録が完了しました」のメールが届くまで待つ（数時間〜48時間）

✅ **完了の確認**: https://developer.apple.com/account をブラウザで開いて
サインインし、「メンバーシップの詳細」が表示されればOK。

### 1-B. Expoアカウント（ビルドに使用・無料）

1. https://expo.dev を開く
2. 右上「**Sign Up**」→「**Continue with GitHub**」を選ぶ（GitHubアカウントで1クリック）

✅ **完了の確認**: expo.dev にログインしてダッシュボードが見えればOK。

### 1-C. Vercelアカウント（AIサーバー用・無料）

1. https://vercel.com を開く
2. 「**Sign Up**」→「**Continue with GitHub**」を選ぶ
3. プランを聞かれたら「**Hobby**」（無料）を選ぶ

✅ **完了の確認**: vercel.com のダッシュボードが見えればOK。

### 1-D. Anthropic APIキー（AI読み取りに使用）

1. https://console.anthropic.com を開いてアカウント作成（既にあればログイン）
2. 左メニュー「**API Keys**」→「**Create Key**」→ 名前は `warranty-vault` などでOK
3. 表示されたキー（`sk-ant-...`）をコピーしてメモ帳などに一時保存
   （この画面を閉じると二度と表示されないので注意）

## STEP 2: AIサーバーを公開する（クリックだけ・10分）

写真のAI読み取りを動かすサーバーです。コマンドは一切使いません。

1. https://vercel.com/new を開く
2. 「**Import Git Repository**」の一覧から `Eather-Arch` の「**Import**」を押す
   （出てこない場合は「Adjust GitHub App Permissions」からリポジトリへのアクセスを許可）
3. 設定画面で次の2箇所だけ変更する:
   - **Root Directory**: 「Edit」を押して `warranty-vault/server` を選択
   - **Environment Variables**: 開いて次を入力
     - Key: `ANTHROPIC_API_KEY`
     - Value: STEP 1-D でコピーしたキーを貼り付け
4. 「**Deploy**」を押して1〜2分待つ
5. 完了画面に出るURL（例: `https://eather-arch-xxxx.vercel.app`）をメモする

✅ **完了の確認**: ブラウザで `メモしたURL/api/extract-warranty` を開いて、
`{"error":"Method Not Allowed"}` と表示されればサーバーは正常に動いています
（ブラウザからは使えない仕様なので、このエラー表示が「正解」です）。

## STEP 3: コマンドを1つ実行する（質問に答えるだけ）

Macのターミナルを開いて、次を1行ずつ実行します:

```bash
cd Eather-Arch/warranty-vault
npm install
npm run setup
```

`npm run setup` が対話形式で以下を**すべて自動で**やってくれます:

1. Expoへのログイン（ブラウザが開くのでログインするだけ）
2. ビルド用プロジェクトの初期化
3. STEP 2 でメモしたVercelのURLの設定（貼り付けるだけ）
4. App Store提出用ビルドの開始

- ビルドはExpoのクラウドで行われるので、**Xcodeのインストールは不要**です。
- 途中で「**Apple IDでログインしますか？**」と聞かれたら **Yes** →
  Apple ID（STEP 1-Aのアカウント）でログイン。**証明書などはすべて自動で作られます。**
- ビルドは20〜40分かかります。ターミナルを閉じても expo.dev の
  ダッシュボードで進捗を確認できます。

✅ **完了の確認**: expo.dev → プロジェクト → Builds に「Finished」と出ればOK。

## STEP 4: App Store Connect の入力（コピペ用文面つき）

### 4-1. アプリを登録する

1. https://appstoreconnect.apple.com を開いてサインイン
2. 「**アプリ**」→ 左上の「**＋**」→「**新規アプリ**」
3. 次のとおり入力:
   - プラットフォーム: **iOS**
   - 名前: `保証書Vault - 家電の保証書・レシート保管庫`
   - プライマリ言語: **日本語**
   - バンドルID: `com.eatherarch.warrantyvault` を選択
     （STEP 3 のビルドで自動登録されています。出てこない場合は数分待って再読み込み）
   - SKU: `warranty-vault-001`（自由な管理用文字列。これでOK）
4. 「作成」を押す

### 4-2. 情報を入力する（以下をそのままコピペ）

**プロモーションテキスト**
```
保証書、どこにしまったっけ？をゼロに。写真を撮るだけで、型番・保証期限・サポート窓口をいつでも数秒で呼び出せます。
```

**説明**
```
家電が壊れたとき、本当に必要なのは「型番」「保証期限」「サポートの電話番号」。
保証書Vaultは、保証書やレシートを写真で撮るだけで、AIが内容を読み取って自動で整理する保管庫アプリです。

◆ できること
・保証書・レシートを撮影 → 名称/型番/購入日/保証期間/店舗/電話番号を自動で読み取り
・読み取り結果は保存前に確認・修正できるので安心
・カテゴリ別の色分けと保証状況バッジで、ひと目で状態がわかる
・名前/メーカー/型番/店舗/メモからすばやく検索
・サポート窓口へワンタップで発信
・写真を使わない手入力にも対応

◆ こんなときに
・冷蔵庫が動かない。保証って切れてた？
・サポートに電話したいのに、型番が本体の裏で見えない
・引っ越しや買い替えで、持っている家電を整理したい

◆ 安心の設計
・登録したデータはすべて端末の中にだけ保存されます
・AI読み取りに使った写真をサーバーに保存することはありません
```

**キーワード**
```
保証書,レシート,家電,保証期限,取扱説明書,型番,管理,収納,整理,サポート
```

**サポートURL**
```
https://5newold111.github.io/Eather-Arch/
```

**プライバシーポリシーURL**
```
https://5newold111.github.io/Eather-Arch/privacy-warranty-vault.html
```
（このページはリポジトリに用意済みで、PRをマージすると自動で公開されます）

**カテゴリ**: プライマリ「ユーティリティ」、セカンダリ「ライフスタイル」

### 4-3. スクリーンショット

シミュレータか実機でアプリを表示してスクリーンショットを撮り、アップロードします。
- 必要サイズ: 6.9インチ（iPhone 16 Pro Max等）と 6.5インチ
- おすすめの3枚: ①一覧画面（何台か登録した状態）②AI読み取りの確認画面 ③詳細画面

### 4-4. App プライバシー（データ収集の申告）

「App プライバシー」→「開始」から:
1. 「データを収集しますか？」→ **「はい」**
2. 「**写真またはビデオ**」にチェック
   - 利用目的: **アプリの機能**
   - ユーザーのIDに紐づけ: **いいえ** ／ トラッキング: **いいえ**
3. それ以外の項目はすべて「収集しない」

（写真はAI読み取りのため一時的に送信されるが保存しない、という実装のとおりに申告する内容です）

### 4-5. ビルドを添付して審査へ

1. ターミナルで `npm run submit` を実行（STEP 3のビルドをApp Storeへ転送）
2. App Store Connect の「ビルド」欄で転送されたビルドを選択
3. 「審査用メモ」に以下をコピペ:
```
写真からのAI読み取り機能は、任意の家電の保証書またはレシートの写真で動作確認できます。読み取りに失敗した場合は手入力フローに誘導されます。アプリ内課金は本バージョンには含まれていません。
```
4. 「**審査へ提出**」を押す

✅ 審査は通常1〜3営業日。結果はメールで届きます。
リジェクトされた場合は、理由の文章をそのままClaudeに貼り付けてもらえれば対応します。
