# 収益化設計 — 無料版 + Pro月額課金

> **現在の状態**: 初回のApp Store公開を最短にするため、課金導線は
> `src/config.ts` の `PAYWALL_ENABLED = false` で**オフ**になっています。
> オフの間は制限なし・通知/CSVも無料で使えます。Pro課金を追加するときは
> 下の「RevenueCat 実装手順」を済ませてからフラグを `true` に変更してください。

## 基本方針

- **無料版で核となる価値を完結させる**: 「型番は？保証はいつまで？電話番号は？」を
  数秒で引き出せる体験は無料のまま。制限は「量」と「便利機能」にかける
- **AIコストと課金を対応させる**: AI読み取りはAPIコストが発生するため、
  無料枠を設けてPro課金で回収する構造にする

## 無料版とProの境界（実装済み）

| 機能 | 無料版 | Pro |
|---|---|---|
| 家電の登録 | 15台まで | 無制限 |
| AI写真読み取り | 月5回まで | 無制限 |
| 手入力での登録・編集・検索・電話発信 | ✅ | ✅ |
| 保証期限の通知（30日前・7日前） | ― | ✅ |
| CSVエクスポート | ― | ✅ |

定数は `src/lib/entitlements.ts`（`FREE_MAX_ITEMS`, `FREE_AI_SCANS_PER_MONTH`）で調整可能。

## 価格案

| プラン | 価格 | 備考 |
|---|---|---|
| Pro 月額 | ¥300/月 | コーヒー1杯以下。心理的ハードルが低い |
| Pro 年額 | ¥2,800/年 | 約22%お得。継続率を上げる主力プラン |

家電の保証は年単位のライフサイクルなので、年額プランとの相性が良い。
AI読み取り無制限のコスト面でも、1回あたり数円程度（Sonnet系・1400px画像）
なので月額¥300で十分に採算が取れる。

## 今後のPro機能候補（フェーズ2以降の提案）

1. **iCloudバックアップ・機種変更時の引き継ぎ** — 端末紛失・買い替えは
   このアプリのデータが最も価値を持つ瞬間。課金理由として最も強い
2. **家族共有** — 家の保証書は家族の共有財産。共有リンク or iCloud共有で実現
3. **複数写真の添付** — 保証書＋レシート＋本体銘板＋延長保証書をまとめて1台に
4. **延長保証・サブスク保証の管理** — 家電量販店の延長保証、AppleCare等の
   期限管理。通知と組み合わせて価値が高い
5. **修理履歴の記録** — 「いつ・どこで・いくらで修理したか」。買い替え判断に有用
6. **PDFレポート出力** — 火災保険・家財保険の請求時に家電一覧を証憑として提出
7. **買い替えリマインダー** — 購入からN年経過した家電を提案（省エネ買い替え時期）
8. **AI問い合わせ文面作成** — 型番・症状からサポートへの問い合わせ文を自動生成

おすすめの優先順位: **1 → 4 → 3**。いずれも「データが増えるほど解約しにくくなる」
方向に働き、月額課金の継続率を支える。

## RevenueCat 実装手順（概要）

1. App Store Connect でサブスクリプション商品を作成
   （`pro_monthly` / `pro_yearly`、サブスクリプショングループ1つ）
2. RevenueCat でプロジェクト作成 → App Store Connect APIキーを接続 →
   Entitlement `pro` と Offering を設定
3. `npx expo install react-native-purchases`（開発ビルドが必要。Expo Goでは動かない）
4. `App.tsx` 起動時に `Purchases.configure({ apiKey: <RevenueCat公開キー> })`
5. `src/lib/purchases.ts` の `purchasePro()` / `restorePurchases()` を
   `Purchases.purchasePackage()` / `Purchases.restorePurchases()` に差し替え、
   `customerInfo.entitlements.active['pro']` の有無で `setPro()` を呼ぶ
6. 起動時にも `Purchases.getCustomerInfo()` で同期（解約の反映）

課金判定はすべて `src/lib/entitlements.ts` 経由なので、差し替え箇所は
`purchases.ts` と起動時同期の2点のみ。
