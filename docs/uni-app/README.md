# うに習慣アプリ — 企画・設計ドキュメント

シーズーの「うに」を相棒にした習慣管理アプリの企画資料をまとめる場所です。
コードは別途、専用のフォルダ（またはリポジトリ）に置きます。

| No. | 文書 | 内容 | 状態 |
|---|---|---|---|
| 01 | [MVV と MVP の定義](./01_mvv-mvp.md) | 存在理由・目指す未来・判断基準、最初に作る機能、収益と寄付の仕組み、技術選定、アプリ名候補 | v0.2 半確定 |
| 02 | （予定）画面設計 | 各画面のスケッチと遷移 | 未着手 |
| 03 | （予定）うにの特徴シートと表情・セリフ集 | 実写から取り出した特徴、5表情の指示書、セリフのトーンガイド | 未着手（写真待ち） |
| 04 | （予定）寄付レポートの書式 | 毎月公開するレポートのひな形 | 未着手 |

## 決まっていること（2026-09-07 時点）

- 絵柄: 実写のうにをもとにしたポケコロ風の2Dアバター
- 寄付: 売上（手数料控除後）の 30% を、リベ大アニマルレスキューとピースワンコ・ジャパンへ
- 公開先: iOS のみ

## 進め方

1. アプリ名と Mac の有無を決める（`01_mvv-mvp.md` 第11章・第12章）
2. うにの写真を受け取り、特徴シート（03）を作る
3. 決まった内容を反映して v1.0 に更新し、画面設計（02）に進む

## 写真の置き場所について

うにの実写写真は `docs/uni-app/reference/` に置きますが、**このフォルダはリポジトリに含めません**（`.gitignore` で除外）。
公開リポジトリに実写を上げないための措置です。
